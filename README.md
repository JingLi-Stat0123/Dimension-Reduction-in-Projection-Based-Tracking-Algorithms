# Dimension-Reduction-in-Projection-Based-Tracking-Algorithms
This repository presents an objective weighting method for multidimensional indicators based on the projection tracking algorithm.


Introduce:
This repository presents an objective weighting method for multidimensional indicators based on the projection tracking algorithm. The background for this work stems from my need to measure a composite 
indicator during my research. Based on relevant literature, this indicator possesses multidimensional attributes with strong correlations among them. To achieve objective weighting and eliminate redundant
information, I have therefore adopted this projection tracking algorithm.

Composition of this repository:
(1)The complete code for the measure
(2)Raw data required for the measurement (partial)
